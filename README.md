# 🥚 달걀 도둑 농장 3D

잠든 보스의 달걀을 훔쳐 와서 내 농장 우리에 심고, 부화한 동물로 돈을 버는 3D 브라우저 게임이에요. 최대 5명이 함께 온라인으로 할 수 있어요.

## 혼자 하기
`달걀도둑3D.html` 파일을 브라우저(크롬/엣지)로 열고 **혼자 하기**를 누르면 돼요.

## 온라인 (최대 5명)
1. 서버를 켤 컴퓨터에 [Node.js](https://nodejs.org) (LTS)를 설치해요. 다른 설치는 필요 없어요.
2. 이 폴더에서 실행해요:
   ```
   node server.js
   ```
   (포트를 바꾸려면 `node server.js 9000`)
3. 서버 창에 나온 주소(예: `http://192.168.0.5:8080`)를 모두 브라우저로 열어요.
4. 타이틀 화면에서 이름과 서버 주소를 넣고 **🌐 온라인 접속**을 눌러요.

- 같은 와이파이에 있는 친구들끼리 바로 할 수 있어요. 다른 곳에 있는 친구는 공유기 포트 포워딩이나 ngrok 같은 터널이 필요해요.
- 처음 실행할 때 Windows 방화벽 창이 뜨면 **허용**을 눌러 주세요.
- 돈·인벤토리·우리는 각자 컴퓨터(브라우저)에 저장돼요. 위치, 우리 모습, 둥지 달걀 상태는 서로 공유돼요.

## 조작
| 키 | 동작 |
|---|---|
| WASD | 이동 |
| Space | 점프 (날고 있을 때는 내리기) |
| Shift + Space / 🪽 버튼 | 날기 (날개가 있을 때) |
| E 또는 클릭 3초 꾹 | 달걀 훔치기 |
| E | 상점 열기 · 우리 빈 칸에 달걀 심기 · 펫/알 들기 |
| R | 들고 있는 달걀 내려놓기 |
| 1~9 | 핫바 칸 고르기 (인벤토리 1~9번 칸) |
| 0 / M | 인벤토리 (100칸) |
| 마우스 휠 | 카메라 줌 |
| ESC | 일시정지 |
