# 🥚 달걀 도둑 농장 3D

## ▶️ [여기를 눌러 바로 플레이하기](https://avocado-kr.github.io/--1/)

**게임 주소:** https://avocado-kr.github.io/--1/

잠든 보스의 달걀을 훔쳐 와서 내 농장 우리에 심고, 부화한 동물로 돈을 버는 3D 브라우저 게임이에요.

## 하는 방법
위의 **플레이 링크**를 열거나, `달걀도둑3D.html` 파일을 브라우저(크롬/엣지)로 열고 **게임 시작**을 누르면 돼요.
돈·인벤토리·우리는 브라우저에 저장돼서, 껐다 켜도 이어서 할 수 있어요.

## 🌐 함께 하기 (최대 5명)
플레이 링크에 **들어오기만 하면 자동으로 같은 방에 접속**해요. 서버 주소를 넣거나 서버를 켤 필요가 없어요.
- 들어온 순서대로 빈 우리를 하나씩 받아요 (1명당 우리 1개, 몸 색 = 우리 색)
- 다른 사람의 모습·이름·우리가 보이고, 누가 훔친 달걀은 모두에게서 사라져요
- 5명이 다 차면 혼자 하기로 들어가요
- 돈·인벤토리·우리는 각자 브라우저에 저장돼요
- 타이틀 화면에서 닉네임을 정하면 내 캐릭터 머리 위에 보여요 (안 정하면 "농부 123" 같은 이름이 자동으로 붙어요)
- 지금 접속한 사람과 같은 닉네임, 욕설·비속어·19금 단어가 들어간 닉네임은 쓸 수 없어요

## 조작
| 키 | 동작 |
|---|---|
| WASD | 이동 |
| Space | 점프 (날고 있을 때는 내리기) |
| Shift + Space / 🪽 버튼 | 날기 (날개가 있을 때) |
| E 또는 클릭 3초 꾹 | 달걀 훔치기 |
| E | 상점 열기 · 우리 빈 칸에 달걀 심기 · 펫/알 들기 |
| R | 들고 있는 달걀 내려놓기 |
| 1~9 | 핫바 칸 고르기 (인벤토리 1~9번 칸) |
| 0 / M | 인벤토리 (100칸) |
| 마우스 휠 | 카메라 줌 |
| ESC | 일시정지 |

## 📱 모바일 조작
휴대폰·태블릿에서도 플레이 링크로 바로 할 수 있어요. 게임은 **항상 가로 화면**으로 나와요 (세로로 들고 있어도 게임이 가로로 돌아가요). 컴퓨터는 그대로예요.

| 조작 | 동작 |
|---|---|
| 왼쪽 조이스틱 | 이동 (살짝 밀면 천천히) |
| 화면 드래그 | 카메라 돌리기 |
| 두 손가락 벌리기/모으기 | 줌 |
| ⤒ 버튼 | 점프 (날고 있을 때는 내리기) |
| ✋ 버튼 | E (상점·심기·펫 들기) · 꾹 누르면 달걀 훔치기 |
| 🪽 버튼 | 날기 |
| ⏸ 버튼 | 일시정지 |
| 아래 핫바 | 칸 고르기 · 🎒 인벤토리 |
